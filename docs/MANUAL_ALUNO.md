# Manual do aluno

1. Abra o endereço informado pelo professor e entre com e-mail e senha.
2. Acesse Trilhas e lições ou Terminal de prática.
3. Leia o objetivo e cada etapa.
4. Digite o comando e pressione Enter.
5. Use Dica ou Inserir comando quando necessário.
6. O comando reconhecido marca a tarefa como concluída. Com Firebase, o progresso fica salvo na nuvem.

## Comandos iniciais
- `pwd`: diretório atual.
- `ls`: lista arquivos e pastas.
- `cd Documentos`: entra na pasta.
- `cd ..`: volta ao diretório pai.
- `cd ~`: pasta pessoal.
- `mkdir redes`: cria diretório.
- `touch arquivo.txt`: cria arquivo.
- `cat arquivo.txt`: exibe conteúdo.
- `help`: lista comandos simulados.

O terminal é simulado e não substitui Ubuntu real. Não insira senhas nem dados pessoais.
