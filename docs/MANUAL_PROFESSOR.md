# Manual do professor e administrador

## Uso didático
Apresente o terminal como simulador seguro e explique a diferença para VM Ubuntu real. Recomende a sequência L01 a L12. Use o painel docente quando Firebase estiver configurado.

## Perfis
1. Aluno cria conta com papel `student`.
2. Professor cria conta pela aplicação.
3. Administrador identifica UID em Authentication e altera `users/{uid}.role` para `teacher` no Firestore.
4. `admin` deve ser concedido somente a gestor institucional autorizado.

## Avaliação formativa
Use tarefas concluídas como evidência de participação, mas valide compreensão por demonstração oral/prática. Observe comando correto, interpretação, autonomia, solução de problemas e conduta segura.

## Privacidade
Colete somente dados escolares necessários. Não solicite CPF, endereço ou senhas; alinhe aviso de privacidade e retenção com a escola.
